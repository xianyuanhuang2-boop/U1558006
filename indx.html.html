GitHub Pages 部署指南

黃絃媛如何將此網站發布至 GitHub Pages？

簡單 5 個步驟，免費獲取黃絃媛專屬的作品集個人網站網址！

1

建立 GitHub Repository

登入 GitHub 帳號，點選右上角的「+」選擇 New repository。

推薦 Repository 名稱設為：hsienyuan-portfolio，並勾選 Public。

2

儲存程式碼為 index.html

將本頁面的原始碼完整複製，在您的電腦中新增文字檔案，存檔為 index.html。

注意：請維持 index.html 全小寫，以便 GitHub Pages 自動辨識為主頁。

3

上傳至 GitHub

使用 Git 指令或直接在 GitHub 儲存庫網頁上按 "Upload files" 拖曳上傳：

git init
git add index.html
git commit -m "Add Huang Hsien-Yuan Portfolio"
git branch -M main
git remote add origin [Your-Repo-URL]
git push -u origin main
4

開啟 GitHub Pages 設定

進入 GitHub Repository 頁面 → 點擊上方 Settings → 在左側選單點擊 Pages。

5

設定 Branch 並公開個人網址！

在 Build and deployment 區塊將 Branch 選擇為 main，資料夾設為 /(root) 後儲存。

等待約 1~2 分鐘，黃絃媛的專屬網址即完成建立：https://[your-username].github.io/hsienyuan-portfolio/
