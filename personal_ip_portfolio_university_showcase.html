部署教學 Guide

如何將此網站免費部署至 GitHub Pages？

簡單 5 個步驟，免費擁有個人專屬網址網站！

1

建立 GitHub 數據庫 (Repository)

登入 GitHub，點擊右上方「+」按鈕選擇 New repository。

將庫存命名為如 my-portfolio 並保持為 Public。

2

準備檔案名稱

將本頁面程式碼複製並儲存為名為 index.html 的檔案。

注意：檔名必須全小寫 index.html，GitHub Pages 才能預設讀取。

3

推送程式碼 (Git Commands)

在電腦終端機開啟該資料夾並執行：

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin [Your-Repo-URL]
git push -u origin main
4

開啟 GitHub Pages 設定

進入該 GitHub Repo 的 Settings 頁籤 → 左側欄找到 Pages。

5

發布與獲取個人網站網址！

在 Build and deployment 區塊下的 Source 選擇 Deploy from a branch，Branch 選擇 main / /root 並點擊 Save。

等待 1~2 分鐘後，您就能獲得網址：https://[username].github.io/[repo-name]/
